# 📊 Spreadsheet Icons Collection

Uma coleção centralizada de ícones profissionais para planilhas, dashboards, ferramentas financeiras e aplicações em Excel/VBA/Web.

## 📁 Estrutura do Repositório

Nesta versão, todos os arquivos de ícones encontram-se reunidos em um único diretório conjunto, identificados pelas nomenclaturas com o padrão **`imagemso`**, facilitando o gerenciamento rápido e direto sem subpastas.

```text
spreadsheet-icons/
├── README.md
├── LICENSE
└── [seus arquivos imagemso-*.png na mesma pasta]
```

## 🚀 Como Adicionar e Atualizar Seus Ícones

1. Adicione os seus novos arquivos `.png` (nomeados com o identificador correspondente `imagemso`) diretamente na pasta do projeto.
2. Abra o terminal na pasta e envie as alterações para o seu repositório no GitHub:
   ```bash
   git add .
   git commit -m "feat: atualiza coleção de ícones de planilhas"
   git push origin main
   ```
